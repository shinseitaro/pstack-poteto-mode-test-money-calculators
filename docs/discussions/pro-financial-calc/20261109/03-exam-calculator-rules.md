# 2026-11-09 pro-financial-calc：試験で使える電卓と、受験生のアプリの使い方

## 背景

触った3つのアプリは、どれも物理電卓のキー配置をまねていた（[02](02-hands-on-results.md)）。B で同じ押し方にするかを決める前に、試験の決まりを Web で調べた。ユーザー：「はい」。

注意：公式のページの多くは直接開けず（CFP Board の PDF はログインの画面に飛ぶ）、予備校などのまとめで確かめたものが多い。数字は試験の前に公式で確かめる必要がある。

## 試験で使える電卓

| 試験 | 使える電卓 | 出どころ |
|---|---|---|
| CFA | **TI BA II Plus（Professional を含む）と HP 12C（Platinum など）だけ**。ほかの電卓を使うと結果が無効になりうる | CFA Institute の calculator policy（2026-01-12 更新、と予備校のまとめ）、[cfainstitute.org](https://cfainstitute.org/en/about/governance/policies/cfa-calculator-policy) |
| FRM（GARP） | TI BA II Plus・Professional、HP 12C の系統 | 予備校・フォーラムのまとめ |
| CFP | TI・HP・Sharp の約11機種。電池式・プログラムできない金融電卓 | CFP Board の案内と予備校のまとめ |
| アクチュアリー（SOA の FM） | TI の BA II Plus、BA-35、TI-30 系だけ | SOA の calculator policy |

- **どの試験も、スマホのアプリは使えない**。本番は物理電卓。
- CFA の受験者は多い：Level I だけで1回に2〜3万人（2025年8月 26,192人、2026年5月 3万1千人以上。CFA Institute の発表）。

## 受験生とアプリ

- 予備校の教材は、BA II Plus か HP 12C の**キーの押し方**で教えている（CFA Institute 自身も「Mastering your calculator」という資料を出している）。
- アプリは、**本番の電卓と同じ押し方を、物理電卓が手元にないときに練習する**ために使われていると思われる。App Store のレビューに「物理電卓をあまり使わなくなった」という声がある。Reddit での使われ方は、今回の検索では見つからなかった。
- **メーカー自身もアプリを出している**：TI の公式の BA II Plus アプリ（iOS、評価2.8）、HP の公式の 12c アプリ（Google Play、有料）。ほかに、BA II Plus をまねたアプリが iOS にも多数ある。

## Claude の考え

1. **試験の勉強に使う人にとって、価値は「本番の電卓と同じ押し方」にほぼ尽きる**。押し方の違う「わかりやすい電卓」は、試験の練習には向かない。
2. 同じ押し方にすると：
   - 特定の会社の製品（TI・HP）をまねることになる。名前はもちろん、見た目のまね（キー配置・色）にも権利の心配がある（CLAUDE.md：「HP 12c」「BA II Plus」は宣伝に使わない）。法律の判断は Claude にはできない。
   - メーカーの公式アプリと、多くのまねアプリと競う。
3. そのため、**B の相手を「受験生」にするのは難しい**。考えられる道：
   - (a) 受験生はやめ、**実務の人**（不動産・融資・ファイナンシャルプランナー）に向けて、押し方にとらわれない「わかりやすい金融電卓」にする。ただし、この人たちが今何を使っているかは調べていない。
   - (b) 受験生向けに、電卓そのものではなく**「キー操作の練習・解説」**（どの順に押すかを教える）にする。電卓をまねないので権利の心配が小さい。市場の大きさは不明。
   - (c) B はいったん止めて、A（LoanChart）に集中する。
4. どれにするかは、ユーザーの判断。
