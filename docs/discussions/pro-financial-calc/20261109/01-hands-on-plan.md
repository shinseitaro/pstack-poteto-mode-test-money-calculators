# 2026-11-09 pro-financial-calc：既存の金融電卓アプリを触る計画

## 背景

A（LoanChart）の v1 を決め終えたあと、Claude は次に「B のターゲットとメッセージを決める」を提案した。ユーザー：

> プロ向け金融電卓のアプリを確認したいです。先に。

A と同じく（[A の 02](../../loan-simulator/20261108/02-hands-on-plan.md)、[08](../../loan-simulator/20261108/08-hands-on-summary.md)）、ユーザーが Android（Pixel 6a）に入れ、Claude が adb で操作して見る。

## 使うアプリ（Claude の提案）

調査（app-store-optimization-explorer の `docs/calculator-deep-dive.md`「プロ用の金融電卓（Android）」）から、無料で入れられる3つ。Google Play の米国のページで確かめた（2026-11-09）。

| アプリ | 推定インストール | 入れる値段 | 広告・課金 | 選んだ理由 |
|---|---|---|---|---|
| BA Financial Calculator（`com.cfa.calculator`） | 約55万 | 無料 | 広告あり | 一番大きい。CFA の試験向けを名前に掲げ、物理電卓のキー配置をまねている |
| 10bII+（`com.anishu.tenbiiplus`） | 約8万（調査の 10bii） | 無料 | 広告なし・アプリ内課金 | 広告のない形。課金で何を売っているかを見る |
| RPN Financial Calculator FNC（`com.arasoft.fnccalc2`） | 約4万 | 無料 | 広告なし・アプリ内課金 | RPN（12c 型の入力）を見る |

- **課金はしない**。何が有料かを見るだけ。
- 総合型の Financial Calculators は A のときに触った（[03](../../loan-simulator/20261108/03-hands-on-financial-calculator.md)）。
- 有料のアプリ（HP 公式 など）は入れない。

## 同じ例で計算する（答えは Claude が計算した値）

| 例 | 入力 | 正しい答え |
|---|---|---|
| 1. 住宅ローン（TVM） | N=360、年3.5%（月払い）、PV=300,000、FV=0 | PMT = **−1,347.13** |
| 2. 返済表（AMORT） | 例1の1〜12回目 | 利息 約 **10,408.23**、元金 約 **5,757.33**、残高 約 **294,242.67**（毎回の丸め方で数セント違うことがある） |
| 3. 積立の将来価値 | 毎月 500 を10年、年5%（月複利） | FV = **77,641.14** |
| 4. NPV・IRR | CF0=−10,000、CF1=3,000、CF2=4,200、CF3=6,800、割引率10% | NPV = **1,307.29**、IRR = **16.34%** |
| 5. 債券の価格 | 表面利率5%（年2回払い）、残り10年、利回り6% | 価格 = **92.5613**（額面100あたり） |

## 見ること

1. 計算が正しいか（上の5つ）。
2. 使い方がわかるか。特に返済表と債券。調査のレビューに「返済表の出し方が YouTube を見ないとわからない」があった。
3. 広告の出方（どこに、何の広告か）と、課金で何を売っているか。
4. 物理電卓のまね（キー）か、入力欄の画面か。
5. 試験で使う人に向けた工夫（キーの説明、例題、試験の電卓との同じさ）。
