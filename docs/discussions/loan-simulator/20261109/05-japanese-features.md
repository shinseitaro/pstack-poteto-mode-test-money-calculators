# 2026-11-09 loan-simulator：日本版の最初の機能と画面（たたき台）

## 背景

日本の Google Play を調べ、4つのアプリを触った（[04](04-japanese-version.md)）。わかったこと：

- 繰上げ返済（期間短縮・返済額軽減を何回でも）、ボーナス返済、元金均等は、個人のアプリにすでにある。
- **変動金利（途中で金利が変わったときの返済）を扱うアプリは無かった**。レビューにも「金利上昇に対応しておらず」。
- 個人のアプリはどれも広告が大きい。広告が無いのは公的機関のフラット35専用のものだけ。

ユーザー：「はい」（日本版の最初の機能と画面を決める相談に進む）。

## Claude の提案

### 芯

**「金利が上がったら、うちの返済はどうなる？」に、広告なしで答える。**
米国版と同じく、広告なし・アカウントなし・データは端末の中だけ。

### 最初の版の機能（8つ）

| | 機能 | 米国版との違い |
|---|---|---|
| 1 | **すぐ計算**：借入額（万円）・金利・期間で、月々の返済額と利息の合計。元利均等と元金均等 | 円・万円。元金均等を足す |
| 2 | **金利が変わったら**：「◯年目から ◯%」を何行でも足す。月々の返済額・総額・完済の月がどう変わるか。追加なしの線と並べたグラフ | **新しい（中心）** |
| 3 | **5年ルール・125%ルール**：入れる／入れないを選べる。入れたとき、返しきれない利息（未払利息）が出たら知らせる | 新しい。銀行によって違うので選べるようにする |
| 4 | **繰上げ返済**：期間短縮・返済額軽減を、時期と金額で何回でも | 米国版の「追加返済」を日本の形に |
| 5 | **ボーナス返済**：借入額のうちボーナスで返す額 | 新しい |
| 6 | **返済予定表**：日付つき、年ごと・月ごと、残高のグラフ、今日の印 | 同じ |
| 7 | **ローンの保存と比べる**：今日の残高、残りの回数。変動と固定（例：フラット35）を並べる | 比べるのは最大3つ |
| 8 | **集めない** | 同じ |

### 入れないもの（あとで考える）

- **住宅ローン控除**：毎年のように制度が変わり、条件（新築・中古、省エネ性能、入居の年）が多い。間違えると信頼を失う。
- **毎月の住まいの費用**（管理費・修繕積立金・固定資産税）：あると便利だが、中心ではない。米国版の「その他の費用」のように1行で足すのは、あとで簡単にできる。
- **借りられる額の逆算**（毎月払える額 → 借入額）：公的機関のアプリにはある。あとの版の候補。
- 銀行の金利の一覧・申込みへの案内：やらない（米国版と同じ約束）。

### 画面

米国版と同じ形（下のタブ「計算」「保存したローン」、右上に設定）。違うのは、計算の画面の開く欄。

```
計算の画面
  月々の返済額（大きく） / 利息の合計 / 1回目の内訳
  入力：借入額（万円）・金利・期間・返済方式（元利均等／元金均等）
  ▸ 金利が変わったら      ← 「6年目から 1.5%」のような行。5年・125%ルールの切り替え
  ▸ 繰上げ返済            ← 期間短縮／返済額軽減
  ▸ ボーナス返済
  ▸ 返済開始の月
  [返済予定表] [保存]
```

### 名前とストア

- 名前は **ローンチャート**（[11](../20261108/11-brand-foundation.md) の決め：日本語でもそのまま使う）。
- コードは同じリポジトリ（`loanchart`）で、計算の部品を共有する。ストアには**別のアプリ**として出す（名前・説明・スクリーンショットを日本向けにするため）。
- 最初は Android とウェブ（米国版と同じ）。

### 確かめる数字の例（Claude が計算）

3,000万円・0.5%・35年・元利均等：月々 77,876円。
6年目（61回目）から 1.5% に上がった場合（5年ルールなしで計算し直すと）：60回払ったあとの残高 約2,602.9万円、61回目から月々 約89,831円、利息の合計 約701.2万円。
同じ時点で100万円の繰上げ返済：期間短縮なら14か月早く終わる。返済額軽減なら月々 約74,884円。

## 追記：変動金利の欄で「2.1」が「10.2」になる（2026-11-09）

ユーザー：「変動金利を入れるボックスで2.1と入れようとすると10.2とはいります」

- ブラウザで同じ操作をして再現した。一番上の「金利（今）」では正しく入り、**足した行の欄だけ**で起きた。
- 原因：足した行の欄は、打つたびに「いまの値」を受け取り直していた。ClojureDart の `f/widget` は、受け取った値が変わると入力欄の中身を作り直すので、そのたびにカーソルが先頭に戻った（2 → .2 → 0.2 → 10.2）。
- 直したこと（loanchart、公開済み）：欄に値ではなく「どこの値か」を渡し、欄の中で読み書きするようにした。繰上げ返済の欄も同じ作りだったので一緒に直った。ClojureDart の手引き（`docs/clojuredart/03`）にも書いた。米国版は、変わる値を受け取る欄がないので起きない。
- 確かめたこと：公開したウェブ版で「2.1」「10」と打って、そのとおりに入ることを確かめた。

## 追記：元金均等で結果の欄が伸びる（2026-11-09）

## 追記：すでに返済中の人はどう使う？（2026-11-09）

ユーザー：「これ、すでにローンを払い始めている人はどうやって使えばいいの？」

- Claude の答え：今の作りは「これから借りる人」向け。返済中の人が使うには、(1) 最初の契約の数字と、これまでの金利の変化を全部入れるか、(2) 今の残高を新しく借りたものとして入れるしかない。(1) は「利息の合計」が借りたときからの合計になり、変動金利の人は過去の変化を全部入れる必要がある。(2) は5年ルールの見直しの時期が今月から数え直しになり、残りの期間が年でしか入らない。
- Claude の提案：最初に「これから借りる／返済中」を選べるようにする。「金利が上がったら、うちの返済は？」は返済中の人のほうが切実。今すぐ足す（おすすめ）か、アンケートを見てから決めるか。
- ユーザー：「その場合は返済中タグみたいなものを作るということでしょうか？」→ 画面の一番上に2つから選ぶ切り替えを置く形を、図で見せた。
- ユーザーの判断：「やりましょう。」

### 作ったもの（loanchart、公開済み）

- 一番上に「これから借りる｜返済中」の切り替え。入れた数字は、それぞれ別に残る。
- 返済中で入れるもの：今の残高（万円）・今の金利・残りの回数・今の返済額（任意。空なら計算）・次の返済の月。銀行の返済予定表や残高のお知らせにある数字。
- 金利の変更は「2028年4月から 1.5%」、繰上げ返済は「2030年3月に 100万円」のように年月で入れる。
- 5年ルールの「返済額の見直しの月」を入れられる。過去の1回（例：借りた月）でもよく、5年ごとに先へ送る。空なら次の返済から5年後とする。今の返済額が計算した額より少なければ、前の見直しで125%に抑えられたとみなす。
- 結果は「これからの毎月の返済額」「これから払う利息」「これからの返済の合計」「完済（あと◯回）」。返済予定表は暦の年ごと。
- 返済中ではボーナス返済は扱わない（毎月の分だけ）。
- 確かめたこと：35年のローンを40回払ったところから「返済中」として入れ直すと、残りの返済額と利息が元のローンの続きと同じになる（5年ルールの見直しの月を含めて）。テストは35個通った。

## 追記：「今の返済額」の説明の場所（2026-11-09）

ユーザー：「今の返済額　のところの文言がよくわかりません。説明を書く場所としては間違っていませんか？」

- Claude の考え：場所が間違っていた。(1) 入力欄の中に薄く「空なら計算」と出していたが、何を空にするのか、何を計算するのかがわからない。(2) 「任意です。空なら…」という説明が、カードの一番下で、銀行の書類の案内とひとまとめになっていた。入れ終わったあとに読む位置で、どの欄の話かも離れている。
- 直したこと（loanchart）：
  - 全体の案内（「銀行の返済予定表や残高のお知らせを見ながら入れてください。」）は、カードの一番上（入れる前に読む位置）に移した。
  - 見出しを「今の毎月の返済額」にし、そのすぐ下に小さく「わからなければ空のままで。残高・金利・回数から計算します」と書いた。欄の中の薄い文字はやめた。
  - 見出しの下に説明を書ける形（`input-row` の `sub`）にしたので、ほかの欄にも使える。
- 画面で確かめた（返済中のカード）。公開はまだ（デプロイのコマンドが自動の許可で止められた）。

### 続き：案内の位置と、文言を選べない件

ユーザー：「『銀行の返済予定表や残高のお知らせにある数字を入れて下さい〜〜〜』の文言の位置の話です。ここですかね？これってローンの条件を入れるところ全体の説明ですよね？」「なぜこういった文言をなぞってコピペ出来なくなっているのですか？これだとアンケートに答えるときに、手間を増やしてしまいます。どの文言も選択不可なんですが」

- Claude は質問を「今の返済額」の欄の説明と取り違え、先にそちらを直していた（上の追記）。
- 案内の位置：「ローンの条件」全体の案内なので、カードの中ではなく、**見出し「ローンの条件」のすぐ下（カードの外）**に移した（返済中のときだけ出る）。
- 文言を選べない理由：Flutter の文字（`Text`）は、ふつうの Web ページと違い、何もしなければ選べない。作るときに選べるようにしていなかった。
- 直したこと：日本版の3つの画面（計算・返済予定表・このアプリについて）を `SelectionArea` で包み、どの文言もなぞって選び、コピーできるようにした。入力欄はこれまでどおり入れられることを画面で確かめた。
- 米国版も同じく選べないまま（まだ直していない）。
