## Claude の考え

### ダークモード → 入れる（おすすめ）

- 端末の設定に合わせて自動で切り替える。アプリの中に切り替えのスイッチは作らない（設定を増やさない）。
- 紹介ページにはすでに暗い色の組み合わせがある（`landing/index.html` の `prefers-color-scheme: dark`）。同じ色を使える。手間は小さい。

### ウェブアプリ → 同時に作る（賛成）

- Flutter は同じコードからウェブにも出せる。nekofuku にも `web/` がある。
- 良いところ：
  - **「いま試せるもの」ができる**。紹介ページや r/alphaandbetausers で「試して」と言える（今は「作る前に聞きたい」としか言えない）。
  - Android より先に、すぐ公開して反応を見られる（ストアの審査がない）。
- 気をつけること：
  - 「データは端末の中だけ」の約束は、ウェブでは「**このブラウザの中だけ**」になる。ブラウザのデータを消すと、保存したローンも消える。そう書く。
  - Flutter のウェブは、最初の読み込みが重く、検索にも出にくい。検索から人を呼ぶ道具にはならない（計算機の検索は減っている、という調査とも合わせて、気にしない）。
  - 計測のタグを入れない約束は、ウェブでも同じ。

### 日本語 → 画面の言葉は最初から2つの言葉にする。日本向けの機能は分けて考える

画面の言葉（英語・日本語）を最初から両方用意するのは、手間が小さく、あとから足すより楽。

ただし、**日本の住宅ローンは米国と中身が違う**。翻訳だけでは日本の人には足りない。

| 項目 | 米国（今の v1） | 日本 |
|---|---|---|
| 毎月の費用 | 固定資産税・保険・PMI・HOA | PMI は無い。マンションは管理費・修繕積立金。固定資産税は年4回の納付 |
| 返し方 | 元利均等だけ | 元利均等と**元金均等** |
| 追加返済 | 毎月・毎年・1回 | **繰上げ返済の「期間短縮型」と「返済額軽減型」**、**ボーナス払い** |
| ほか | — | 住宅ローン控除、団体信用生命保険（ふつう金利に含まれる） |

日本の市場はまだ調べていない（README「市場の調査で残っていること」）。
Claude のおすすめ：**v1 は画面の言葉だけ日本語にも対応し、日本向けの機能（元金均等・繰上げ返済の2つの型・ボーナス払い・日本の毎月の費用）は、日本の市場を調べてから決める**。

## 追記：作ったもの（① の一部・②・③）

loanchart に、① 計算（入力3つ・家の費用・開始日・前回の入力の保存）、② 返済スケジュール（月ごと・年ごと・今日の印）、③ 追加返済（毎月・毎年・1回だけ・隔週払い）を作った。数字は stitch-prompts.md の値とテストで照らした。

- ダークモード：ユーザーの「はい」を、端末に合わせて入れることへの答えとして受け取り、入れた。
- **利息の合計は、返済表（毎月セント単位に丸める）の合計にした**：$300,000・3.5%・30年で **$184,970**（式だけで出すと $184,968.26）。同じ画面の追加返済の説明（Without extra）と食い違わないようにするため。stitch-prompts.md の「$184,968」は式で出した値。
- 隔週払いは「毎月、月々の支払い ÷ 12 を追加で払う」として計算し、そう画面に書いた（約315回、利息約 $26,400 減。stitch-prompts.md の値と同じ）。

- Claude の考え：
  - `.top` はすすめない。迷惑メール・詐欺によく使われてきた TLD で、迷惑なものとして扱われやすい（Reddit の投稿は `netlify.app` のリンクでも消された）。「信頼できる」を芯にする、お金の分野のブランドと合わない。
  - `.fyi` は `.top` よりずっと良い。ただ意味（for your information）がアプリとは少しずれる。1年目が安く、更新が高い登録業者が多いので、**更新の値段**で比べる。
  - おすすめは `.app`（アプリのための TLD、HTTPS が必須）。`.app` と `.fyi` の更新の値段の差が小さければ `.app`。
- まだ決めていない。購入はユーザーが行う。

## 追記：ウェブ版を公開した

ユーザー：「1」（ウェブ版を公開する）。

- **https://loanchart.netlify.app/app/** に公開した（紹介ページと同じ Netlify のプロジェクト）。紹介ページの「We're building it now.」に「Try the early version」のボタンを足した。
- 公開の前に見つけたこと：Flutter のウェブ版は、ふつうにビルドすると、開くたびに **Google のサーバー（gstatic.com）から描画の部品とフォントを読み込む**。「何も外に送らない」と合わないので、
  - フォント（Roboto、OFL）をアプリに入れ、
  - `--no-web-resources-cdn` でビルドした。
  - きれいなブラウザで開いて、アプリが外に通信していないことを確かめた（記録に残ったのは Chrome 自身の通信だけ）。
  - Roboto に無い「→」を使っていた所は「to」に変えた。
- ウェブ版では「保存は this browser の中だけ」と出るようにした（アプリでは this device）。
- **公開して見つけたこと：Netlify が無料プランのサイトに「Powered by Netlify」のバッジ（スクリプト）を入れている**。ウェブ版では下のタブ「My loans」に重なる。紹介ページにも入っている。2026-08-19 以降に作ったプロジェクトは最初から有効。Netlify の管理画面（Project configuration → General → Powered by Netlify badge）で消せる。外への通信は確認されなかったが、「no tracking scripts」と書いたページに他社のスクリプトが入るのは避けたい。**ユーザーに消してもらう**。
- ユーザーがバッジをオフにした（「OFF にしました」）。紹介ページと /app/ の両方で、バッジのスクリプトが入らなくなったことを確かめた。
- 紹介ページのボタン：Claude は「Try the early version」と書いた。ユーザー：「try the early version というのはおかしいのでは？ web version を try してみて、くらいでいいのでは？」→ **「Try the web version」**に変えた。まだ途中であることは、下の文（「It is still early」）で伝える。一番上の見出しの下にも置いた（ユーザー：「ここからウェブ版に行くリンクがありません」。下の方にしか無かった）。
