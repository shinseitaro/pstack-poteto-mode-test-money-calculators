# 2026-11-08 既存のアプリを使ってみる（5）複利計算機（Android）

## 背景

[06-hands-on-car-loan](06-hands-on-car-loan.md) に続く5つ目で、最後。複利の専用アプリ。
ユーザーがインストールし、Claude が adb で操作した。日本の端末・日本の Play ストアで動かしている。

## アプリ

| | |
|---|---|
| 名前 | Compound Interest Calculator（日本語の表示は「複利計算機」「利息計算機」） |
| パッケージ | `com.codexception.interest_calculator`、バージョン 1.0.16 |
| インストール数 | 約46万（前回の調査の推定。Play ストアの表示は「100K+」） |
| 中身 | 複利の計算。「基本」と「高度」の2つのモード |

## 最初の同意の画面

起動すると、利用規約とプライバシーポリシーへの同意を求める画面が出る。

- 必須：プライバシーポリシーと利用規約に同意する
- 任意（「おすすめ」と書かれている）：使用統計とクラッシュレポートの共有に同意する

**ユーザーの判断**：Claude がユーザーに確認し、「OK」をもらってから、**必須の方だけ**にチェックを入れて進めた。

5つのアプリのうち、最初に同意を求めたのはこのアプリだけ。

## 計算の正しさ（02 の例3）

| 項目 | 正しい答え | このアプリ | 合っているか |
|---|---|---|---|
| 月ごとの複利（基本モード） | $12,517.96 | 12,518（実質年率 4.594%） | 合っている（整数に丸めている） |
| 日ごとの複利（高度モード、初期設定の360日の年） | $12,523.05 | 12,523（実質年率 4.602%） | 合っている（整数に丸めている） |

金額はいつも整数に丸められ、セントが出ない。端末の言語に合わせて通貨が「¥」になっているためかもしれない。

## 気になった点：「360日の年」が初期設定

高度モードの「年のタイプ」は、初期設定が **360日の年**。このままだと、複利の頻度の選択肢が次のようになる。

| 頻度 | このアプリ（360日の年） | ふつうの数え方 |
|---|---|---|
| 隔週 | 年に **25** 回 | 年に 26 回 |
| 毎週 | 年に **51** 回 | 年に 52 回 |
| 毎日 | 年に 360 回 | 年に 365 回 |

iOS のレビューにあった「隔週払いは年26回のはずが、違う回数で計算している」と同じ種類の誤り。

ただし、**お金への影響はとても小さい**。例3の条件（$10,000、年4.5%、5年）で比べると：

| | 360日の年 | 365日の年 | 差 |
|---|---|---|---|
| 隔週 | $12,520.69 | $12,520.79 | $0.10 |
| 毎週 | $12,521.98 | $12,522.01 | $0.03 |
| 毎日 | $12,523.05 | $12,523.05 | ほぼ 0 |

お金への影響は小さいが、「隔週は年25回」という表示は、お金に詳しい人が見ると、信頼を落とす点になりそう。

## 機能

- 基本モード：初期値、利率（年・月など）、期間、毎月の積立と、積立のタイミング（月の初めか終わり）。入れるとすぐに結果が変わる。
- 高度モード：年のタイプ、複利の頻度（毎月・年・半年・四半期・二か月・半月・隔週・毎週・半週・毎日）、
  積立と引き出しを複数入れられる。
- 結果：終了残高、投資総額、利息の合計、実質年率、残高の推移のグラフ（年ごと）。
- メニュー：計算の保存と読み込み、PDF への書き出し、設定。
- 結果の下に「これらはすべてのシミュレーションです。インターネット上の何者かのアプリに基づいて、投資や生活費を決定しないでください」と書いてある（機械翻訳のような日本語）。
- **見た目は5つの中で一番今どき**（Material Design の部品、落ち着いた色）。

## 広告と課金

- **画面の一番上に広告**が出る。出たのは不動産の査定の広告（三井のリハウス）。
- アプリの中には、全画面の広告・起動したときの広告・動画を見ると特典がもらえる広告の仕組みもたくさん入っている。
  約3分使った範囲では、全画面の広告は出なかった。
- **アプリの中で「プレミアム」を買える**：「広告を削除し、新しいテーマをアンロックします」。
  5つの中で、アプリの中で広告を消せるのはこれだけ。値段は、課金の画面に触らない約束なので確かめていない（Play ストアの Web ページにも出ていなかった）。

## 作り（アプリの中身を調べた）

- 広告：Google AdMob。課金：Google Play の課金。
- 求められる権限：インターネット、広告用の ID と広告の測定、Play ストアの課金とライセンスの確認など。位置情報や連絡先は求めていない。

## 気づいたこと（Claude の考え。まだ決めたことではない）

1. **今どきの見た目で、機能も十分**。5つの中で、見た目と使いやすさはこのアプリが一番よい。
   それでも「360日の年」のような細かい所で、お金に詳しい人の目には引っかかる点がある。
2. **複利の計算機は、ローンの計算機と使う人が違う**。預金や積立を考える人向けで、入力も結果も別物。
   A に含めるなら、ローンとは別の画面になる。
