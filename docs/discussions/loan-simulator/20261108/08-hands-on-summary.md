# 2026-11-08 既存のアプリを使ってみた：5つのまとめ

## 背景

[02-hands-on-plan](02-hands-on-plan.md) の計画どおり、Google Play の上位のアプリを5つ使った（Android、Pixel 6a）。
ユーザーがインストールし、Claude が adb で操作して、画面と作りを見た。
アプリごとの記録は 03〜07。ここでは横に並べて、[01-target-and-message](01-target-and-message.md) の未決の4つに何が言えるかをまとめる。

注意：

- 日本の端末・日本の Play ストアで動かした。広告の中身は日本向けで、米国とは違う可能性がある。
- 1つのアプリを3分ほど使っただけ。全画面の広告は、どのアプリでも出なかったが、長く使うと出る可能性がある（どのアプリにも仕組みは入っていた）。
- iOS のアプリは触っていない。

## わかったこと

1. **5つとも計算は正しかった**。iOS のレビューで多かった誤り（平均の利息、下取りの税金、隔週払いの回数）は、
   Android の上位アプリでは起きていなかった。小さな引っかかりは、複利計算機の「360日の年」（隔週が年25回）くらい。
2. **広告はどれにもあり、お金の判断と関係のない広告や、判断を邪魔する広告が出る**。
   服、お菓子、求人、そしてローンの計算機に消費者金融の広告（「審査通過しました。50万円利用可能です。」）。
   ユーザーの感想：Financial Calculators を見て「このアプリの広告はひどいですね・・・」。
3. **広告を消す道は、ほとんど無いか、見つけにくい**。有料版がある2つでも、買った人は1%前後。
4. **「単純で見やすい」と「細かい機能」を両方持つアプリは無い**。
   単純なアプリ（ローンと預金の計算ツール）も、細かいアプリ（Karl's）も、200万以上インストールされている。
5. **返済スケジュールに日付を出し、「何か月目から」の追加返済を入れられるのは Karl's だけ**。ただし使いにくい。

## 未決の4つへの影響（Claude の考え。まだ決めたことではない）

### 1. 最初の市場

- このまとめは日本の端末で見たもの。米国の広告がここまでひどいかはわからない。
- 日本の広告（消費者金融、不動産の査定）を見ると、**日本でもお金の計算機に広告の問題がある**ことはわかった。
  日本の市場を調べる意味はありそう（app-store-optimization-explorer の HANDOFF 4.1 の3）。
- 判断は変えず、「米国を先に」のままでよいと考える。ただし日本も候補として残す。

### 2. 主役のターゲット

- 返している人（③）に要る機能（日付つきの返済スケジュール、「何か月目から」の追加返済）を持つのは Karl's だけで、それも使いにくい。
  ③を主役にすると、差をつけやすい。
- 車を買う人（①）向けには、Car Loan Payment Calculator が項目も計算も正しく、差をつけにくい。ただし見た目は古く、広告がひどい。
- 「②家・③返済中を主役」のたたき台は、そのままでよいと考える。

### 3. 複利・積立を含めるか

- 複利の計算機は、入力も結果もローンと別物で、使う人も違う。今どきのアプリ（複利計算機）もすでにある。
- **A からは外し、ローンに絞る**のがよいと考える。

### 4. 伝えることの芯と約束

たたき台の6つの約束を、次のように並べ直すのがよいと考える。

| 約束 | 使ってみてわかったこと | 扱い |
|---|---|---|
| 広告は出さない | どのアプリにもあり、判断を邪魔する広告まで出る | **一番の約束**。「快適」ではなく「あなたのお金の判断を、ほかの誰かの商売で邪魔しない」 |
| 買ったときのまま、あとから悪くしない | 有料版があっても1%しか買わない。「払えば消える」では伝わらない | 一番の約束とセットにする（「最初から広告が無い。あとからも足さない」） |
| 自分の契約に合わせて見られる（日付・追加返済・保存） | Karl's だけが持っていて、使いにくい | **二番目の約束**。「開いてすぐ計算できて、要るときだけ詳しく」 |
| 正しい数字と、その理由が見える | 5つとも正しかった | 売りにはしない。当たり前の条件。「理由が見える」（1か月目の利息の内訳など）は、わかりやすさの一部として残す |
| データは自分の端末に、消えない | 確かめていない | 残す |
| 余計な情報を集めない | どのアプリも広告用の ID を使う。1つは同意の画面で統計の共有を「おすすめ」している | 一番の約束を支える根拠として残す |

**芯は「信頼できる」のままでよいが、その中身は「正確」より「邪魔しない」と「わかりやすい」に寄せる**。
