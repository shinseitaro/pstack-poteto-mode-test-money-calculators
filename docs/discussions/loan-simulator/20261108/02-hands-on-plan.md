# 2026-11-08 既存のアプリを使ってみる：何を見るか

## 背景

[01-target-and-message](01-target-and-message.md) のたたき台について、ユーザーから
「既存のアプリを使ってみたほうがいいとおもいます」。
レビューや宣伝画像だけでは、広告がどの瞬間に出て、どれくらい嫌なのかがわからない。
そのため、未決の4つは、実際に使ってから決めることにした。

使うのはユーザー。Claude はこの Linux から Mac や iPhone を操作できない。
M1 以降の Mac なら、Mac App Store で iPhone アプリを入れられる
（調べた計算機アプリはすべて「Designed for iPad」で Mac に対応。app-store-optimization-explorer の `HANDOFF.md` 4.1）。

## 使うアプリ

| アプリ | 選んだ理由 |
|---|---|
| Loan Calculator‰ | いちばん人気（評価10.6万件）。広告だけで、課金なし。入力3つの1画面 |
| Loan Calculator - Debt Planner | 広告とサブスクなど7種類の課金。追加返済を入れられる |
| Loan Calculator - Loan2Me | 広告なし・$9.99 の買い切り。多機能で★4.83。A の方向にいちばん近い |
| Compound Interest Calc | 複利（質問3）を判断するため。広告あり、広告削除 $1.99 |

## 同じ例で計算する（答えは Claude が計算した値）

どのアプリにも同じ数字を入れ、答えと見せ方を比べる。

### 例1：住宅ローン（$300,000、年3.5%、30年）

| 項目 | 正しい答え |
|---|---|
| 月々の返済 | **$1,347.13** |
| 1か月目の利息 | **$875.00**（「平均の利息」は $513.80。この2つを取り違えていないか） |
| 総利息 | $184,968.26 |
| 毎月 $200 を追加で返すと | 287回で完済（73か月早まる）、利息が $42,090 減る |
| 隔週払い（月々の半額を2週ごと＝年26回） | 約315回分で完済、利息が約 $26,400 減る（計算の細かい方法で少し変わる） |

### 例2：車のローン（車 $35,000、下取り $10,000、頭金 $3,000、消費税7%、年7.5%、60回）

| 項目 | 正しい答え | 下取りを頭金と同じに扱った場合（よくある誤り） |
|---|---|---|
| 消費税 | **$1,750**（下取りを引いた $25,000 にかかる） | $2,450 |
| 借りる額 | $23,750 | $24,450 |
| 月々の返済 | **$475.90** | $489.93 |

州によって扱いが違う（下取りを引かない州もある）。どの州として計算するか選べるかも見る。

### 例3：複利（$10,000、年4.5%、5年、追加の積立なし）

| 複利の頻度 | 5年後 |
|---|---|
| 日ごと | $12,523.05 |
| 月ごと | $12,517.96 |
| 四半期ごと | $12,507.51 |
| 年ごと | $12,461.82 |

## 見ること

| 何を | なぜ（どの質問に関係するか） |
|---|---|
| 広告：いつ、どこに、どれくらい出るか。結果を見る前に動画広告があるか | 約束「広告は出さない」の重さ（質問4） |
| 課金：いつ、どう勧められるか。広告を消すにはいくらか | 買い切りにいくらまで払えそうか |
| 開いてから例1の答えが出るまでの時間・操作の数 | 「すぐ計算できる」の基準 |
| 上の例の答えが合っているか。どう見せているか | 約束「正しい数字と、その理由が見える」（質問4） |
| 追加返済・返済スケジュール・保存・比較があるか、使いやすいか | 返している人（③）に足りているか（質問2） |
| 車のローンの項目（下取り、税金、APR）があるか | 車を買う人（①）を主役にできるか（質問2） |
| 求められる権限。アカウントの登録が要るか | 約束「余計な情報を集めない」（質問4） |
| 使っていて、いちばん嫌だったこと・よかったこと | 伝えることの芯（質問4） |
| 自分ならどのアプリにお金を払うか。払うならいくらか | 市場とターゲット（質問1・2） |

アメリカの人の立場で使うのが前提（質問1が米国の場合）。日本の市場を考えるなら、
日本の App Store で「住宅ローン 計算」などを検索し、上位のアプリも1〜2個入れてみる。
