# 2026-11-08 既存のアプリを使ってみる（2）Karl's Mortgage Calculator（Android）

## 背景

[03-hands-on-financial-calculator](03-hands-on-financial-calculator.md) に続く2つ目。
ユーザーがインストールし、Claude が adb で操作した。日本の端末・日本の Play ストアで動かしている。

## アプリ

| | |
|---|---|
| 名前 | Karl's Mortgage Calculator（作者 Karl Jeacle、個人） |
| パッケージ | `com.drcalculator.android.mortgage`、バージョン 4.1 |
| インストール数 | 約226万（前回の調査の推定） |
| 中身 | 住宅ローン専用。タブは INPUT・TABLE・GRAPH・CHART・SUM の5つ |

## 計算の正しさ（02 の例1）

| 項目 | 正しい答え | このアプリ | 合っているか |
|---|---|---|---|
| 月々の返済 | $1,347.13 | 1,347.13 | 合っている |
| 1か月目の利息 | $875.00 | 875.00（1か月目の元金の返済が 472.13） | 合っている |
| 毎月 $200 の追加返済 | 73か月早まる、利息が $42,090 減る | 6年1か月早まる、42,090 減る、完済日 2050年9月1日 | 合っている |

**すべて合っていた。** 車のローンと複利は、このアプリには無い。

## 機能

- **返済開始日**を入れられ、返済スケジュールに**年と月が出る**（年ごと・期間ごと・回ごとに切り替え）。完済日も出る。
- **追加返済がとても細かい**：毎月・半年ごと・毎年・一度だけの4種類。それぞれ「何か月目から」を指定できる。
  ほかに Extra・Fixed・Int の切り替えもある（Int は金利の変更と思われる。確かめていない）。
- 物件価格・頭金（金額か%）、毎月の費用2つ（税金や保険を入れる欄）。
- 保存：「Load / create」で複数のローンを作って切り替えられる。「Backup / restore」もある。
- 結果：一覧（SUM）、グラフ、円グラフ（利息・元金・追加返済の割合。古い立体的な円グラフ）、メール・SMS で送る。
- 数字の入力は、アプリ独自の数字キーの画面に切り替わる（CLR・DEL・ENTER）。
- 通貨の記号は端末の言語に合わせて「￥」になった。
- 見た目は暗い背景。項目ごとに色（水色・緑・赤・オレンジ）が違い、にぎやか。

## 広告と課金

- **画面の下に広告**が出る。どれも日本向けの広告だった（海外 eSIM のアプリ、大阪府の正社員の求人）。
- 約3分使った範囲では、全画面の広告は出なかった。ただし、アプリの中には全画面の広告（Interstitial）の仕組みも入っている。
- **広告を消すには、別の有料版を買う**。メニューの「Remove ads」を押すと、有料版の Play ストアのページが開く。
  - 有料版：Karl's Mortgage Calculator Pro、**$2.49**（米国の Play ストア）
  - 説明は「無料版からの変更は、広告を消したことだけ」
  - **ダウンロード数は 1万以上**。無料版の約226万に比べると、**有料版を買った人は1%に満たない**（Play ストアの表示は「10K+」なので大まかな比較）。

## 作り（アプリの中身を調べた）

- 広告：Google AdMob（画面の下の広告と、全画面の広告）。
- 求められる権限：インターネット、広告用の ID、端末の基本的な状態（`READ_BASIC_PHONE_STATE`）など。位置情報や連絡先は求めていない。
- アプリの中で課金する仕組みは無い（有料版は別のアプリ）。

## 気づいたこと（Claude の考え。まだ決めたことではない）

1. **このアプリも計算は正しく、機能は1つ目よりさらに細かい**。日付つきの返済スケジュール、「何か月目から」の追加返済、
   ローンの保存まである。03 で「違いになりそう」と書いたことのうち、機能の面はこのアプリがすでに持っている。
2. **それでも、広告を消すのに $2.49 払った人は1%に満たない**。「広告なしの有料版」は、すでに安い値段で用意されている。
   それでもほとんどの人が無料版を使っている。A の「お金を払うか（未確認）」に対して、厳しい材料になる。
   - ただし、有料版があることが無料版の中でどれくらい伝わっているかはわからない（メニューの奥にある）。
   - iOS では「広告がつらい、有料でもいいから」というレビューが多かった。Android と iOS で払う人の割合が違う可能性もある。
3. **残っている違いは、「わかりやすさ」と「信頼できる見た目」かもしれない**。
   このアプリは機能が多いが、項目ごとに色がばらばらで、独自の数字キーの画面に何度も切り替わる。
   入力欄の名前（Pre・Extra・Fixed・Int）も、初めての人にはわかりにくい。
