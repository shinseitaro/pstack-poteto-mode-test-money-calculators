# 2026-11-08 既存のアプリを使ってみる（4）Car Loan Payment Calculator（Android）

## 背景

[05-hands-on-loan-deposit-tool](05-hands-on-loan-deposit-tool.md) に続く4つ目。車のローンの専用アプリ。
ユーザーがインストールし、Claude が adb で操作した。日本の端末・日本の Play ストアで動かしている。

## アプリ

| | |
|---|---|
| 名前 | Car Loan Payment Calculator（Sunflower Solutions） |
| パッケージ | `com.sunflowersolutions.autoloanpmtcalcfree`、バージョン 3.0.3.2 |
| インストール数 | 約33万（前回の調査の推定。Play ストアの表示は「100K+」） |
| 中身 | ディーラーから買う、個人から買う、買える車の価格の逆算、リース |

## 計算の正しさ（02 の例2）

| 項目 | 正しい答え | このアプリ | 合っているか |
|---|---|---|---|
| 消費税（下取りを引いた額にかける） | $1,750 | 1,750.00 | 合っている |
| 借りる額 | $23,750 | 23,750.00 | 合っている |
| 月々の返済 | $475.90 | 475.90 | 合っている |
| 総利息 | 約 $4,804 | 4,804.00 | 合っている |
| 1か月目の利息 | $148.44 | 148.44 | 合っている |
| 隔週払い（年26回） | $219.34 | 219.34 | 合っている（月々を半分にした $237.95 や、12/26 倍の $219.65 ではない） |
| 毎週払い（年52回） | $109.61 | 109.61 | 合っている |

**すべて合っていた。** iOS のレビューにあった「隔週払いの回数の誤り」「下取りの税金の誤り」は、このアプリでは起きていない。

## 機能

- 入力の項目が実際の車の購入に合っている：車の価格、下取り、値引き（リベート）、頭金、ディーラーの手数料、
  そのほかの費用（延長保証など）、消費税率、金利、下取り車の残りのローン、期間（月）。
- 「下取りに消費税をかけない」「値引きに消費税をかけない」「消費税もローンに含める」を切り替えられる（どれも最初はオン）。
  州によって違うことも書いてある。
- 結果：月々・隔週・毎週の返済額、借りる額、消費税、総利息、総支払額。返済スケジュール（日付は無い）。
- 保存と書き出しは有料版だけ（「BUY THE PRO APP TO EXPORT LOAN DATA AND SAVE LOAN/LEASE SCENARIOS」のボタンが常に出ている）。
- 使いにくい所：
  - 結果が画面の下にあり、計算してもスクロールしないと見えない。説明にも「下までスクロールして」と書いてある。
  - ラベルは「$」なのに、入れた数字は「￥35,000.00」と表示される（端末の言語に合わせている）。
  - 返済スケジュールの回数の列が、右の数字と少しずつずれていく。
  - 見た目は古い（灰色の背景、明朝体のような文字、角の丸い青いボタン）。

## 広告と課金

- **画面の一番上に、どの画面でも広告が出る**。出たのは**カードローン（消費者金融）の広告**だった：
  - 「年収300万・複数借入でもOK！最短20分・初回金利0円。スマホ完結で月1000円〜！」
  - 「**審査通過しました。50万円利用可能です。**」（申し込んでいないのに、審査に通ったように見せる文言）
- アプリの中には、全画面の広告・起動したときの広告・動画を見ると特典がもらえる広告の仕組みがたくさん入っている。
  約3分使った範囲では、全画面の広告は出なかった。
- **有料版**：Auto Car Loan Payment Calc Pro、**$6.99**、ダウンロード数 **1,000以上**。
  無料版（Play ストアの表示で10万以上）に比べて、**買った人は1%前後**。

## 作り（アプリの中身を調べた）

- 広告：Google AdMob（画面の上の広告、全画面、起動したとき、動画）。
- 求められる権限：インターネット、広告用の ID と広告の測定、Play ストアのライセンスの確認など。位置情報や連絡先は求めていない。

## 気づいたこと（Claude の考え。まだ決めたことではない）

1. **4つとも計算は正しかった**。車のローンの細かい点（下取りの税金、隔週払い）まで正しい。
   Android の上位アプリでは、「正確さ」は差にならない。
2. **ローンを計算している人に、別の借金を勧める広告が出る**。これは「広告がうるさい」より重い問題だと思う。
   車のローンを考えている人は、まさにお金の判断をしている最中で、消費者金融の広告は判断を誤らせかねない。
   「広告なし」を、単に「快適」ではなく、**「あなたの判断を、ほかの誰かの商売で邪魔しない」**という意味で伝えられるかもしれない。
   ただし、これは日本の端末で出た広告。米国で同じような広告が出るかはわからない。
3. **有料版を買う人は、ここでも1%前後**。$2.49（Karl's）でも $6.99（このアプリ）でも同じくらい。
   値段より、「有料版がある」と知られていない・必要と感じられていないことが大きいのかもしれない。
