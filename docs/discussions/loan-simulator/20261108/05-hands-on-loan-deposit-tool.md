# 2026-11-08 既存のアプリを使ってみる（3）ローンと預金の計算ツール（Android）

## 背景

[04-hands-on-karls-mortgage](04-hands-on-karls-mortgage.md) に続く3つ目。前回の調査で、Google Play の「amortization calculator」（返済スケジュールの計算機）の上位に出たアプリ。
ユーザーがインストールし、Claude が adb で操作した。日本の端末・日本の Play ストアで動かしている。

## アプリ

| | |
|---|---|
| 名前 | ローンと預金の計算ツール（日本語に翻訳されている。パッケージ名はトルコ語で「ローン計算」） |
| パッケージ | `com.pixelsdo.kredihesaplama`、バージョン 24.00 |
| インストール数 | 約221万（前回の調査の推定） |
| 中身 | 個人ローン・住宅ローン・ビジネスローンの3つ。比較リスト、お気に入り |

## 計算の正しさ（02 の例1）

| 項目 | 正しい答え | このアプリ | 合っているか |
|---|---|---|---|
| 月々の返済 | $1,347.13 | 1,347.13 | 合っている |
| 総利息 | $184,968.26 | 184,968.26 | 合っている |
| 1か月目の利息 | $875.00 | 875.00 | 合っている |

**合っていた。** 金利は年利として扱われている。返済期間は「月」で入れる（30年なら 360）。

入力の途中で、借入額が 300000 ではなく 30,000 になったことがあった。Claude が adb で文字を送ったときに抜けた可能性が高く、アプリの問題かはわからない。

## 機能

- 入力は4つ：借入額、返済期間（月）、金利、開始日。とても単純。
- 結果：月々の返済、総返済額、総利息、完済日。
- 返済予定表：回数・返済額・利息・元金・残債。**各回の日付は出ない**（開始日と完済日だけ）。
- PDF・Excel への書き出し、共有、メール。比較リスト、お気に入り（保存）。
- **追加返済は無い**。住宅ローンの税金・保険などの項目も無い。
- アプリの名前は「ローンと預金」だが、預金の計算機は見当たらなかった。
- 見た目は青と白で、1つ目・2つ目より今どき。ただ、崩れている所がある：
  - 返済予定表の上の「開始日」「完済日」が途中で切れている。
  - メニューのロゴが画面の一番上の表示に重なり、「プライバシーポリシー」が下のボタンに重なっている。

## 広告と課金

- **画面の下に大きな広告**が、どの画面にも出る。画面の高さの約7分の1。
  出たのはふるさと納税の広告（お菓子とみかん）で、お金の計算とは関係がない。
- アプリの中には、起動したときの広告（App Open）、全画面の広告、動画を見ると特典がもらえる広告の仕組みが入っている（AdMob と AppLovin）。
  約3分使った範囲では、起動したとき・画面を戻ったときに全画面の広告は出なかった。
- **広告を消す方法は無い**（メニューにも、アプリの中の課金の仕組みにも見当たらない）。

## 作り（アプリの中身を調べた）

- 広告：Google AdMob（AppLovin も入っている）。
- 求められる権限：インターネット、広告用の ID と広告の測定、端末の基本的な状態、**端末のファイルを読む**（`READ_EXTERNAL_STORAGE`）など。
  ファイルを読む権限は、書き出しのためと思われるが、計算機には要らない権限に見える。

## 気づいたこと（Claude の考え。まだ決めたことではない）

1. **3つとも計算は正しかった**。Android の上位アプリでは「計算が間違っている」は起きていない。
   「正確です」を主役の売りにするのは、少なくとも Android では難しい。
2. **このアプリは、単純さと今どきの見た目で221万インストールまで来ている**。機能は3つの中でいちばん少ない。
   iOS の Loan Calculator‰（入力3つの1画面、評価10.6万件）と同じく、「開いてすぐ計算できる」ことが選ばれている。
3. **3つとも、広告を消す方法が無いか、メニューの奥にしかない**。
   「広告なし」を売りにするなら、「最初から広告が無い」「買い切りで、あとから広告を足さない」と、はっきり見せる必要がある。
4. 3つを並べると、**「単純で見やすい」と「細かい機能」を両方持つアプリは無い**。
   - 単純で見やすいが、機能は少ない：このアプリ
   - 機能は細かいが、色がばらばらで、わかりにくい言葉が並ぶ：Karl's Mortgage Calculator
   - 何でもあるが、計算機が20個並び、古い見た目：Financial Calculators
