# 2026-11-08 loan-simulator のターゲットと「伝えるべきこと」

## 背景

A（loan-simulator：ローン・複利の計算機）のブランドづくりを始める。
ユーザーの希望：「いきなり名前の案を出すのではなく、まずはターゲット（誰が、どんな場面で使うか）と、
既存アプリへの不満から見える『伝えるべきこと』を一緒に整理したい」。

根拠にした調査：`../../app-store-optimization-explorer/docs/calculator-deep-dive.md`（調査日 2026-10-09、米国）。

## Claude の提案（たたき台）

### 1. ターゲット：誰が、どんな場面で使うか

調査から、A を使う人を4つに分けた。

| | 誰が | 場面 | 何が要るか | お金を払いそうか |
|---|---|---|---|---|
| ① | 車を買う人 | ディーラーで、営業と話しながら条件を比べる | すぐ答えが出ること、下取りと税金の正しい扱い、APR | 中くらい。一度きりの利用になりやすい |
| ② | 家を買う人 | 物件を見たあと、銀行の提案を受けたとき | 税金・保険・PMI を含めた月々の支払い、条件の比較 | 高い。借りる額が大きく、計算の誤りが痛い |
| ③ | ローンを返している人 | 「追加で返したらどうなるか」を考えるとき | 追加返済、返済スケジュール、保存したローン | 高い。何度も使い、データを残したい |
| ④ | 積み立てる人 | 高金利の預金や CD を選ぶとき | 複利の頻度（日ごと・月ごと）、積立 | 低め。単純な計算で済み、無料の計算機が多い |

検索の動きとの対応（調査「1. 金利と検索の推移」）：

- 自動車ローン（①）：金利が倍近くになっても検索はほぼ一定。定番の需要。
- 住宅ローン（②③）：金利が下がったとき（2020年）に増えた。
- 複利（④）：預金金利が上がったとき（2022〜2024年）に増えた。

**提案：主役は②と③（住宅ローン・車ローンを組む人と返している人）、④は補助。**

- 大きなお金が動く場面なので、「広告なし」「正確」の価値がいちばん高く、買い切りにお金を払う理由がある。
- 「契約前に比べる」→「返しながら見直す」と、同じ人が長く使い続ける流れが作れる。保存したデータが消えないことにも価値が出る。
- ④は使う人も気持ちも違う。ブランドの中心に入れると、伝えることがぼやける。

### 2. 既存アプリへの不満から見える「伝えるべきこと」

低評価レビュー297件の分類（調査「低評価レビューの中身」）から。

| 不満 | 裏にある気持ち | 伝えるべきこと |
|---|---|---|
| 広告 41%（2026年は68%） | 大事な計算の最中に邪魔される。足元を見られている感じがする | 広告は出さない |
| 更新で悪くなった 17% | 前は良かったのに、あとから変えられた | 買ったときのまま、あとから悪くしない（買い切りの意味） |
| 計算が間違っている 12% | この数字を信じて契約していいのかわからない | 正しい数字と、その理由が見える |
| 保存したデータが消える 8% | 入れた情報を大事に扱ってもらえない | データは自分の端末に、消えない |
| 不要な権限 4% | お金の情報を抜かれていそう | 余計な情報を集めない |
| 機能が足りない 9% | 実際の契約に合わない | 追加返済・返済スケジュールなど、実際に使う項目がある |

**提案：伝えることの芯は「信頼できる」。**
広告を出さないことは、それ自体を売りにするというより、「あなたの判断の邪魔をしない」という姿勢の証拠になる。

注意点：

- **「正確です」と言うだけでは信じてもらえない**。どのアプリも同じことを言っている。
  他のアプリが間違えている点を具体的に見せる方が伝わる。例：
  - 1か月目の実際の利息（平均の利息ではない。$30万・3.5%・30年なら $875）
  - 隔週払いは年26回（月13回分）になる
  - 下取り車の分には消費税がかからない
- **単純さを捨てない**。一番人気の Loan Calculator‰ は入力3つの1画面だけ。
  「開いてすぐ計算できて、要るときだけ詳しく見られる」ことも約束に入れるべき。
