## v1 の機能

1. **すぐ計算**：借りる額・金利・期間の3つで、月々の支払いと利息の合計。前回の値を覚えておく。月々の支払いは、押すと出し方（式と入れた値）が出る。
2. **1回目の内訳**：1回目の支払いのうち、利息と元金がいくらか。利息は、押すと出し方が出る（例：$300,000 × 3.5% ÷ 12 = $875.00）。
3. **家の費用**：物件価格と頭金、固定資産税、保険、PMI、HOA、**その他の毎月の費用**（光熱費・修繕など。金額はユーザーが入れ、アプリは推測しない）。月々の合計を内訳つきで。開くまで隠す。
4. **返済スケジュール**：日付つき、月ごと・年ごと、残高のグラフ、今日の行に印。
5. **追加返済**：毎月・毎年・1回だけを「何か月目から」で。隔週払い（年26回）。早く終わる月数と減る利息。結果は、押すと出し方が出る（追加のぶん元金が減り、翌月からの利息が減る。追加なし・ありの利息の合計）。
6. **ローンの保存**：名前をつけて保存。今日の残高、あと何回。
7. **比べる**：2〜3つの条件を並べ、月々・利息の合計・終わる日・差額。
8. **集めない**：アカウントなし、広告用の ID なし、統計の送信なし。データは端末の中だけ。

## 画面（5つ＋設定）

開くとすぐ①。説明・同意・広告の画面は出さない。詳しい項目は同じ画面の中で開いて出す。下のタブは2つ。

```
[計算]  ←→  [保存したローン]          右上：設定
   │              │
   ├ 返済スケジュール   └ 比べる
   └ 追加返済（下から出るシート）
```

| | 画面 | 中身 |
|---|---|---|
| ① | 計算 | 入力3つ、月々の支払い（大きく）、利息の合計、1回目の内訳。「Home costs」「Extra payments」「Start date」を開くと出てくる |
| ② | 返済スケジュール | 日付つきの表（日付・元金・利息・残高の4列。月々の支払いは表の上に1回）、月ごと・年ごと、残高のグラフ（追加返済なしの線と並べる） |
| ③ | 追加返済 | 下から出るシート。「毎月 $200、2027年1月から」のような行を足す。結果：早く終わる期間、減る利息 |
| ④ | 保存したローン | カードの一覧（名前、今日の残高、終わる日、月々）。2〜3つ選んで比べる |
| ⑤ | 比べる | 横に並べた表と、一番安いものとの差 |
| | 設定 | 通貨と表示、書き出し・読み込み、「このアプリが集めないもの」 |

画面の見た目は Google Stitch で試した（プロンプト：[`design/stitch-prompts.md`](design/stitch-prompts.md)、画面：[`design/stitch/`](design/stitch/README.md)、記録：[10](../docs/discussions/loan-simulator/20261108/10-stitch-screens.md)）。

返済スケジュールの表は4列（日付・元金・利息・残高）。月々の支払いは表の上に1回だけ出す（[10](../docs/discussions/loan-simulator/20261108/10-stitch-screens.md)）。

## 「どう計算したか」を見せる数字（[2026-11-09/02](../docs/discussions/loan-simulator/20261109/02-reflect-reddit-into-v1.md)）

数字を押すと、同じ画面の中に短い説明が開く。対象は3つだけ：月々の支払い、1回目の利息、追加返済の効果。
理由：「計算機は中が見えない」「計算機ごとに答えが違う」という声が多く、人柄の「正直：数字の理由を見せる」と合う。ただし、これだけで他と差がつくわけではない。
